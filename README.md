# Giáo Án Upper Body Toàn Diện — Theo Dõi Mức Tạ

Trang web tĩnh (HTML/CSS/JS) chuyển thể từ giáo án 12 bài tập Upper Body, bổ sung **cột Mức tạ (Set 1 & Set 2 - kg)**, tự động lưu trên trình duyệt (`localStorage`), có đồng hồ đếm giờ nghỉ và lịch sử buổi tập.

## Đẩy lên Vercel cực nhanh

1. Cài Vercel CLI (nếu chưa có):
   ```bash
   npm i -g vercel
   ```
2. Chạy lệnh trong thư mục dự án:
   ```bash
   vercel
   ```
   Hoặc push thư mục này lên GitHub rồi vào [vercel.com](https://vercel.com) chọn **Add New Project** → Import repo là xong (không cần cấu hình build).
